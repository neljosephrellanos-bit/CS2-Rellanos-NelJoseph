# Electricity Bill Calculator

## This program calculates a person's electricity bill by analyzing their meter readings and using formulas to find the exact amount.

## Version 2 - Updated code with input validation
- Input: Accepts customer's name with their previous and current meter readings.
- Process: Calculates total electricity bill to pay and displays total bill.
- Output: Total bill in Philippine Peso.

## Input Validation: 
- Checks whether or not name inputted is not blank.
- Previous meter reading is greater than 0.
- Current meter reading is greater than or equal to 0.
