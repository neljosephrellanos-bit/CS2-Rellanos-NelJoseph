# Electricity Bill Calculator

## This program calculates a person's electricity bill by analyzing their meter readings and using formulas to find the exact amount, with validation rules in place to keep the program running smooth and efficiently.

## How to run the code:
1. Open the code in online GDB, Google Colab, or code.org Python Lab.
2. Run the program.
3. Enter the values required for the program to calculate your electricity bill.
4. Check the displayed output on the screen.

## Version 2 - Updated code with input validation
- Input: Accepts customer's name with their previous and current meter readings.
- Process: Calculates total electricity bill to pay and displays total bill.
- Output: Total bill in Philippine Peso.

## Input Validation: 
- Checks whether or not name inputted is not blank.
- Identifies if the previous meter reading is greater than 0.
- Checks if the current meter reading is greater than or equal to the previous meter reading.
